# Reference Implementation

The living reference for this pattern is the VictoryMarche game project
(private). Its structure, in brief:

- `AGENTS.md` — contains the "Persistent Project Wiki (Wiki Brain)" mandate.
- `Victory Marche - Wiki/Wiki Home.md` — entry point with identity + links.
- `Victory Marche - Wiki/PROMPT-LEDGER.md` — 20+ rows accumulated in a single
  working day, including honest PARTIAL/FAILED entries and UPDATE notes.
- `Victory Marche - Wiki/Systems/` — pages for Building, Unit Movement,
  Messenger Driven Orders, Terrain Shader, Procedural World Generation, each
  written the same session the system changed.

If your integration looks like that after a day of work, it is working.
